# Exam Score Prediction using Linear Regression

## About the Project

I used Linear Regression to predict students' exam scores based on different student habits and performance-related features.

I explored the dataset, handled missing values, trained the model and checked how well the predictions matched the actual exam scores.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## What I Did

- Explored and cleaned the dataset
- Handled missing values
- Selected features and target variable
- Split the data into training and testing sets
- Trained a Linear Regression model
- Evaluated the predictions
- Compared actual and predicted scores

## Result

The Linear Regression model achieved an **R² score of 0.8732**, meaning it explained around **87.3% of the variation** in exam scores.

**MAE:** 4.59  
**RMSE:** 5.70

Overall, the model gave a good result on the test data.
